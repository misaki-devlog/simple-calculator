# simple-calculator

## 概要（Overview)
２つの数値を入力して、四則演算（足し算・引き算・掛け算・割り算）を行うぷグラムです。
This program takes two numbers as input and performs basic arithmetic operations.

## 使い方（Usage）
1. Pythonをインストールする
   Install Python

2. ターミナルで以下を実行する
　　Run the following command

    calculator1.py
   
3. 数字を入力すると計算結果が表示されます
   Enter numbers and the results will be displayed
